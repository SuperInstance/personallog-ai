# PersonalLog

> Your life, indexed and searchable.

**[personallog.ai](https://personallog.ai)**

A personal log that's actually searchable. Voice notes, text entries, photos, locations. Ask it anything. It remembers so you don't have to. Private by default — your data never leaves your device.

## What It Does

- **Log anything** — Voice note, photo, text, location. Two taps, no organization needed
- **Natural language search** — "When did I last talk to Sarah?" "What was that restaurant Mike recommended?"
- **Auto-tagging** — Dates, locations, people, topics extracted automatically
- **Recurring reminders** — "Remind me in 6 months about the dentist." Set once, forget it
- **Private by default** — Everything on device. No cloud, no account, no ads
- **Export anytime** — Full JSON export. Your data is yours

## Tech Stack

- Cloudflare Workers (edge deployment)
- Single-file HTML response
- Custom domain via Cloudflare
